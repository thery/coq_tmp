praeclarum (UITP 2003)

Let x, y, z, t : Prop. If x → z and y → t then (x ∧ y) → (z ∧ t).

  • Suppose x ∧ y.
    • We get z by x → z, since
      • we have x.
    • We get t by y → t, since
      • we have y.
    Altogether we have z ∧ t.

square_pos (UITP 2003)

Let a, b ∈ ℤ. If 0 < a < b then a a < b b.

  • It is equivalent to prove 0 < b b − a a.
    • That can also be written as 0 < (b + a)(b − a).
      • From 0 < a < b we have 0 < b + a ∧ 0 < b − a.

exp_pos (UITP 2003)

Let x ∈ ℝ and y ∈ ℤ. If 0 < x, to prove 0 < xy, we have three cases:

  • If 0 < y then x1 ≤ xy.
  • If 0 = y then xy = 1.
  • If y < 0 then xy = 1 / x−y.

praeclarum (xtext)

Let x, y, z, t : Prop. Assume (x → z) ∧ (y → t) (h1) and x ∧ y (h2). We prove z ∧ t.

  • Going back to the definition of and (and_ind) in h1, we prove z ∧ t:
    • Assume x → z (i) and y → t (j). Going back to the definition of and (and_ind) in h2, we prove z ∧ t:
      • Assume x (k) and y (l).
        • Applying i to k, we have z.
        • Applying j to l, we have t.
        So by definition of and (conj), we have z ∧ t.

Trans_Inv (xtext)

Let E : Set. Let R : Rel E. Assume Trans E R (h). We prove Trans E (Inv E R).

  • Let us choose arbitrarily x, y, z ∈ E; assume Inv E R x y (h1) and Inv E R y z (h2).
    • By h we have Trans E R, that is ∀ x₀ y₀ z₀ ∈ E, R x₀ y₀ → R y₀ z₀ → R x₀ z₀.
    • By h2 we have Inv E R y z, that is R z y.
    • By h1 we have Inv E R x y, that is R y x.
    By application, we have R z x, that is Inv E R x z.
  • We have proved ∀ x₀ y₀ z₀ ∈ E, Inv E R x₀ y₀ → Inv E R y₀ z₀ → Inv E R x₀ z₀, that is Trans E (Inv E R).
