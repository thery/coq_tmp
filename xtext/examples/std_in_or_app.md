# in_or_app

Let `A : Type`{.var}. Let `l m : list A`{.var}. Let `a : A`{.var}. We prove `In a l \/ In a m -> In a (l ++ m)`{.claim}.

- To prove `In a l \/ In a m -> In a (l ++ m)`{.fact} by induction (list, list_ind), we generalise it to `forall l0 : list A, In a l0 \/ In a m -> In a (l0 ++ m)`{.fact}:
- Case 1 (base): we prove `In a nil \/ In a m -> In a (nil ++ m)`{.claim}.
  - Assume `False \/ In a m`{.hyp} (H).
    - We prove `In a m`{.fact} by case analysis on `False \/ In a m`{.fact} (H) (or, or_ind):
    - Case 1.1: we prove `False -> In a m`{.claim}.
      - Assume `False`{.hyp} (H0).
        - By contradiction (False, False_ind), from `False`{.fact} (H0) we can deduce `In a m`{.claim}.
    - Case 1.2: we prove `In a m -> In a m`{.claim}.
      - Assume `In a m`{.hyp} (H0).
        - By H0 we have `In a m`{.claim}.
    - We have `In a m`{.claim} in all cases *by eapply (@or_ind (False) (In a m) (In a m)); cbv beta; eauto*.
- Case 2 (inductive): we prove `forall (a0 : A) (l0 : list A), (In a l0 \/ In a m -> In a (l0 ++ m)) -> In a (a0 :: l0) \/ In a m -> In a ((a0 :: l0) ++ m)`{.claim}.

                  - By IHl we have `In a l0 \/ In a m -> In a (l0 ++ m)`{.claim}.
                  - We deduce `In a (l0 ++ m)`{.claim}.
              - We have proved `In a m -> In a (l0 ++ m)`{.claim} (H10).
