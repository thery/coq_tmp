# Nat.add_comm

Let `n m : nat`{.var}. We prove `n + m = m + n`{.claim}.

- Thus we have `forall x y : nat, x = y -> x + m = m + x <-> y + m = m + y`{.claim}.
  - Let us choose arbitrarily `x : nat`{.var} and `y : nat`{.var}.
    - Assume `x = y`{.hyp} (H).

        - We deduce `Morphisms.respectful eq iff (eq (x + m)) (eq (y + m))`{.claim} *by firstorder*, that is `forall x0 y0 : nat, x0 = y0 -> x + m = x0 <-> y + m = y0`{.fact}.

    - We have proved `x = y -> x + m = m + x <-> y + m = m + y`{.claim}.
- Using add_0_r we get `forall n0 : nat, n0 + 0 = n0`{.claim} *by Stdlib.Arith.PeanoNat.Nat.add_0_r*.

- We have proved `0 + m = m -> Basics.flip Basics.impl (0 + m = m) (m = m)`{.claim}.

    - In particular `Morphisms.ProperProxy eq m`{.claim}, that is `m = m`{.fact}.
