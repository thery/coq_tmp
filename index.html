coq_tmp

Pages of github.com/thery/coq_tmp: proofs written as text, checked step by step, and the tools around them.

Try it in the browser

Rocq runs in your browser, nothing to install: Rocq in the browser, a build of rocq-web by Rayane Boudrouss (rocq.rboud.com), with many thanks to him. Step through a file with Alt+↓; the first visit reloads the page once.

  • The cyp tutorial One file to step through: what a proof text means, the conditions it generates, how cyp proves them, justifications, errors.
  • cyp: texts as proofs A proof written as text, checked step by step; a wrong step and its message.
  • xtext: proofs as text ExtractText writes the proof of a lemma as text, in English or French.
  • Proof by pointing Select part of a goal and click Point: the tactic that brings it to the surface is written for you.
  • Mathematical Components mathcomp 2.6.0, with Hierarchy Builder, in the same browser.

Read

  • Proof texts Proofs written as text by xtext from Rocq proof terms, in ten languages, and checked by cyp: each as a web page (formulas as mathematics, colours you can switch) and as a PDF.
  • The cyp tutorial The same tutorial as a document, with every example checked.

Use the tools

  • cyp Checks a proof written as text (Markdown with coloured formulas) step by step in Rocq.
  • xtext Writes a Rocq proof as text, after Y. Coscoy's thesis, in ten languages.
  • prooftext The shared format, and its PDF and web pages (Typst).
  • pbp Proof by pointing: the tactic and the pattern computed from a selection.
  • elpi-tools A debugger, a property tester and a VS Code debug adapter for Elpi programs.
  • radcan A reflective simplifier of radical expressions.
